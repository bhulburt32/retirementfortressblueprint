# Retirement Fortress Blueprint — logo

Files (all type is outlined, so nothing depends on fonts being installed):

- rfb-mark.svg / .png — the app mark: the fortress on the navy blueprint tile (rounded square). Use for app icons, favicons, avatars.
- rfb-mark-plain.svg — the same without the blueprint grid, for very small or printed uses.
- rfb-mark-on-navy.svg — the fortress alone, no tile, for placing on an existing navy background.
- rfb-mark-512/256/128/64.png, favicon.ico — ready-made icon sizes.
- rfb-logo-horizontal.svg / .png — mark + wordmark, for light backgrounds (page headers, documents).
- rfb-logo-horizontal-dark.svg / .png — the same for navy backgrounds (deck covers, the app masthead).
- rfb-logo-stacked.svg / .png and -dark — centred version for covers, splash screens and square placements.

The mark tells the Fortress story: the moat (the waves), the Foundation (gold), the Walls (the towers) and the
Roof (the keep), with Alto's red as the pennant. Colours are Alto's: navy #001F5B, red #E70000, gold #D9A93C,
cream #F5F2ED. Type: Playfair Display Bold (wordmark, Blueprint in italic) and Montserrat SemiBold (eyebrow).
Keep clear space of at least the pennant's height around the lockups; don't recolour the fortress or stretch it.
